Admin login setup

Google Apps Script → Project Settings → Script Properties-এ নিচের দুইটি property রাখুন:

  1. TARUNNO_ADMIN_EMAIL — Admin-এর email address
  2. TARUNNO_ADMIN_PASSWORD — শক্তিশালী আলাদা password
  3. Save করে Apps Script-এর নতুন version deploy করুন।
পুরোনো TARUNNO_ADMIN_KEY public form/API-এর অন্য protected action-এ লাগতে পারে; এটি Login password হিসেবে ব্যবহার করবেন না।
