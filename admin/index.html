Google Apps Script setup

একবার setup না করলে Admin CRUD কাজ করবে না।

  1. Google Sheet-এর linked Apps Script খুলুন।
  2. ZIP-এর codegs/Code.gs দিয়ে পুরোনো কোড replace করুন, save করুন।
  3. Script Properties-এ TARUNNO_ADMIN_KEY নামে private key যোগ করুন।
  4. setupTarunnoSheets() একবার run করুন; অনুমতি চাইলে authorize করুন।
  5. Deploy → Manage deployments → Edit → New version → Deploy করুন।
  6. এখানে একই key দিয়ে Connect করুন।
কোনো key না সেট করলে admin read/write বন্ধ থাকবে। Admin panel public website-এ দৃশ্যমান হলেও data mutation backend key ছাড়া সম্ভব নয়।
